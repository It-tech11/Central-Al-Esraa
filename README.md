# سنترال الإسراء - الموقع + لوحة التحكم

## المحتوى
- `server.js` — الباك إند (Node.js + Express + رفع صور)
- `data/store.json` — قاعدة بيانات المنتجات (بالعربي والإنجليزي)
- `public/index.html` — الموقع اللي بيشوفه الزباين (يدعم عربي/إنجليزي + فاتح/غامق)
- `public/admin.html` — لوحة تحكم صاحب السنترال (تعديل أسعار، رفع صور، إضافة منتجات)
- `public/uploads/` — هنا بتتخزن صور المنتجات المرفوعة

## طريقة التشغيل محلياً

1. لازم يكون عندك Node.js (نزّله من nodejs.org لو مش موجود)
2. افتح Terminal جوه فولدر المشروع:
   ```
   npm install
   ```
3. اعمل نسخة من `.env.example` باسم `.env` وغيّر فيه:
   ```
   cp .env.example .env
   ```
4. شغل السيرفر:
   ```
   npm start
   ```
5. افتح:
   - الموقع: http://localhost:3000
   - لوحة التحكم: http://localhost:3000/admin.html (admin / admin123 افتراضياً، غيّرها في .env)

## المميزات اللي فيه

- **دعم لغتين**: زرار EN/AR في الهيدر بيبدل كل نصوص الموقع فوراً، وبيحفظ اختيار الزائر (المرة الجاية هيفتحله بنفس اللغة)
- **نظام فاتح وغامق**: زرار 🌙/☀️ بيبدل الثيم، وبرضه بيتحفظ للزيارة الجاية
- **رفع صور من لوحة التحكم**: صاحب السنترال يقدر يرفع صورة حقيقية لأي منتج بدل الأيقونة الافتراضية
- **تعديل الأسعار مباشرة** من نفس الصفحة، وإضافة منتجات جديدة (بالعربي والإنجليزي)
- **فورم الطلب** فيه: الاسم، رقم الهاتف، رقم بديل (إجباري)، العنوان، والإيميل (اختياري) — والطلب بيتحول رسالة واتساب جاهزة

## قبل النشر الحقيقي (مهم)

- غيّر `JWT_SECRET` و `ADMIN_PASSWORD` في `.env` لقيم قوية وسرية، ومتترفعش على GitHub
- لو هتستضيفه أونلاين، تأكد إن فولدر `uploads` بيتعمله باك أب دوري (الصور بتتخزن كملفات على السيرفر مش في قاعدة البيانات)
- الاستضافة اللي بتدعم رفع الملفات بشكل دائم (زي Render مع Persistent Disk) أفضل من اللي بتمسح الملفات كل شوية
